# Electricity Calculator

## Description
This program calculates the electric bill for the user.

## Version 1 - Original code without input validation
- Input: Accepts a student's name and two meter readings.
- Process: Calculates the total electricity consumption.
- Output: Total electricity consumption.
- Does not include input validation.

## Version 2 - Updated code with input validation
- Input: Accepts a student's name and two meter readings.
- Process: Calculates the total electricity consumption.
- Output: Total electricity consumption.
- Does include input validation.
